# Image Classification Data Annotation — Boots vs Sneakers

## Project Overview

This project demonstrates a manual image annotation workflow for a binary footwear classification dataset.

The goal is to classify images into two categories: **Boots** and **Sneakers**, using consistent labeling guidelines and a reproducible Python-based workflow.

## Tools and Technologies

- Python
- Google Colab
- Pigeon Jupyter
- Pandas
- CSV

## Dataset

The project uses a collection of 45 footwear images, organized for manual labeling.

## Annotation Workflow

1. Extract and load the image dataset.
2. Define the classification labels.
3. Display each image using an interactive annotation interface.
4. Assign labels based on predefined classification rules.
5. Export completed annotations to CSV.
6. Review labels for consistency, completeness and potential errors.

## Quality Assurance

The quality review documents any ambiguous images, labeling corrections and completeness checks performed after annotation.

## Deliverables

- Reproducible annotation notebook
- Completed annotation CSV
- Labeling guidelines
- Quality review report
- Representative annotated samples

## Skills Demonstrated

Image classification, manual data labeling, annotation tooling, data organization, Python, dataset preparation and quality assurance.
